📘 Visão do Projeto

PT-BR:
Aplicação simples de lista de tarefas (To-Do List) desenvolvida com HTML, CSS e JavaScript puros. Ideal para aprendizado de manipulação do DOM, eventos e armazenamento local.

EN:
A simple To-Do List application built with HTML, CSS, and JavaScript. Great for learning DOM manipulation, events, and local storage.

⚙ Funcionalidades

Adicionar tarefas à lista

Marcar tarefas como concluídas

Remover tarefas

Armazenamento local para persistência de dados

🖼 Demonstração

🧪 Como Rodar

Clone o repositório:

git clone https://github.com/laviniacarol/rid-188998.git


Navegue até o diretório do projeto:

cd rid-188998


Abra o arquivo index.html em seu navegador.

Para uma experiência mais dinâmica, utilize a extensão Live Server do Visual Studio Code.
